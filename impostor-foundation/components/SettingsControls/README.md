# Settings controls
Host settings rows: 54px tall, label in 16px 700 with a 12px `ink-dim` hint, control on the right, 1px `#1B2547` divider.

- **Stepper**: 36px square `line-100` buttons with − and +, value in 18px Russo One `yellow-500`, 76px wide.
- **Toggle**: 60 × 32 pill, `green-500` when on and `line-200` when off, 26px white knob. Use `<button aria-pressed>`.
- **Segmented**: `surface-300` track with 3px padding, options 32px tall at radius 8px; selected `cyan-500` with `cyan-ink` text.
- **Preset pills**: 40px, `radius-pill`, 2px border; selected `yellow-500` border, `#2A2410` fill and `yellow-500` text.
