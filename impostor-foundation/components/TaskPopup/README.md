# Task popup
The device frame every task and sabotage fix uses. 560 × 420, centred over the dimmed game.

- Frame `panel-bg`, 1px border at `rgba(148,163,184,0.18)`, radius 16px, `shadow.panel`, padding 16px 20px.
- Header: a 44px number badge (1px `panel-accent` border, mono digits; `!` and `panel-alert` for sabotage fixes), the task name in 18px Chakra Petch 600 uppercase with 0.06em tracking, room and type in `mono-caption` `panel-muted`, and a 44px close link.
- Work area: 520 × 284, `panel-inset` with a 16px grid at 4% opacity, radius 12px.
- Footer: the hint on the left (13px, `#9AA5B5`), the status in 12px mono on the right.
- Exactly one accent. Meters are segmented (3px gaps, radius 2, empty `rgba(148,163,184,0.1)`). Controls are outlined, not filled. Done shows a ringed check in `green-500` with TASK COMPLETE in mono.
