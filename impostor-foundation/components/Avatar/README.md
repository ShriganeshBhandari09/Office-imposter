# Avatar
The player robot. Colour from `avatar-*`; trim is that colour at 72% brightness; 3.5px `#0A0F1E` outlines.

- Eyes `#7CF3FF`; `red-500` only on an impostor's own screen.
- States: alive; ghost (50% opacity, wavy tail, no legs, no shadow); body (rotated 90°, X eyes in `red-500`).
- Hats replace the antenna: cap, headset, hard hat, beanie.
- Sizes: 30px on the map, 48px in meetings, 64px in the lobby, 220–300px on full-screen moments. Height is 1.25 × width.
